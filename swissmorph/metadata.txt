about=SwissMorph is a QGIS 3 Processing plugin that automatically downloads
    swissALTI3D 2 m or 0.5 m DTM tiles from the swisstopo STAC API and derives
    seven morphometric layers in EPSG:2056 (CH1903+/LV95):
    Slope, Plan curvature, Profile curvature, TWI, SPI, LS factor, TPI.
    The area of interest can be defined by typing Swiss municipality names
    (resolved via geo.admin.ch) or by drawing a rectangle on the map canvas.
    Automatic symbology is applied when layers load into the project.
    No external tools required -- pure Python + rasterio + numpy.
